# WoW Paper Doll for D&D5e — v0.4.0
Foundry VTT v14 module.

## v0.4.0
- Bundles the supplied WoW empty PaperDoll slot artwork as the defaults.
- Layout changed to two six-slot side columns and six bottom slots, inspired by the supplied Paper Doll configuration screenshot.
- Adds a client setting: **Automatically open Paper Doll with character sheet**.
- Keeps right-click item assignment and per-actor custom slot icons.
- Supports one Paper Doll window per actor rather than one global window.

Enable the auto-open option under **Game Settings → Configure Settings → Module Settings → WoW Paper Doll for D&D5e**.
